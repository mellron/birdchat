## SQL Objects Created by TPP-10200 (already built — use these)

### Staging Table: `EActiveLOCCollateralData`

| Column | Type | Notes |
|--------|------|-------|
| IID | int IDENTITY | PK |
| AsOfDate | datetime | Previous business day |
| PledgeCode | typPledgeCode | |
| ReferenceNumber | varchar(25) | Unique ID |
| MaturityDate | datetime | |
| Amount | numeric(20,2) | Full LOC balance |
| RunTime | datetime | Batch run timestamp |

### Stored Procedure 1: `SSISLoadActiveLOCCollateralData`
- **Purpose:** Loads data into `EActiveLOCCollateralData` from CPMS source tables
- **Source tables:** `tblPldgPool` JOIN `tblLetterOfCredit` ON PldgCd, with `CPMSStat` for CurrDt
- **Filter logic:**
  - `P.LofC = 1` (pledge pool flagged as Letter of Credit)
  - `L.Status = 'Active'`
  - `CurrDt BETWEEN IssueDate AND MaturityDate`
- **AsOfDate:** Calculated via `fnGetPreviousBusinessDate(CPMSStat.CurrDt)`
- **Retention:** Deletes records older than 13 months
- **New logic (added 2/25/2026):** Issue Date must be >= previous business day (AsofDate)

### Stored Procedure 2: `SSISActiveLOCCollateral`
- **Purpose:** Returns formatted file rows from `EActiveLOCCollateralData` for the last batch run
- **Output rows (in order):**
  1. `"HDR"|"YYYYMMDD"` — AsOfDate of most recent runtime batch
  2. `"AsOfDate"|"PledgeCode"|"ReferenceNumber"|"MaturityDate"|"Amount"` — column header
  3. Data rows — pipe delimited, double-quoted
  4. `"TLR"|"0000000001"` — zero-padded 10-digit count of data rows
- **Identifies "last batch"** by `WHERE runtime = (SELECT MAX(runtime) FROM EActiveLOCCollateralData)`

### Function: `fnGetPreviousBusinessDate(@InputDate DATE)`
- Walks backward from input date skipping weekends and holidays in `syn_vCPMSHoliday`
- GRANT EXECUTE to `SystemsSupport`

## Output File Specification

**Filename:** `LOCActive_MMDDYYYY` (date in filename = run date)
**SSISConfigurations key:** `LOC_Collateral.txt`
**Format:** Pipe `|` delimited, double-quoted, one row per line

### File Layout Example

```
"HDR"|"20260310"
"AsOfDate"|"PledgeCode"|"ReferenceNumber"|"MaturityDate"|"Amount"
"20260307"|"AB12"|"REF00001"|"20270101"|"500000.00"
"20260307"|"CD34"|"REF00002"|"20271215"|"250000.00"
"TLR"|"0000000002"
```
