# TPP-0001: Environment-Based TreeView Background Colors

## Overview

This change allows the TreeView navigation panel background color to be configured per environment via `app.config`. Previously, only UAT and Parallel environments had a hardcoded yellow background. Now each non-production environment can have its own configurable color, while Production retains the default system color.

Users can still override the color at runtime by right-clicking on the TreeView to open a color picker dialog.

## Configuration

### Setting Environment Colors

Edit `BSDRateUI/app.config` in the `<applicationSettings>` section under `<BSDRate.My.MySettings>`:

```xml
<!-- TPP-0001 detolle - Environment-specific TreeView background colors (excluding Production) -->
<setting name="DevEnvironmentColor" serializeAs="String">
    <value>LightBlue</value>
</setting>
<setting name="ITEnvironmentColor" serializeAs="String">
    <value>LightGreen</value>
</setting>
<setting name="UATEnvironmentColor" serializeAs="String">
    <value>Yellow</value>
</setting>
<setting name="ParallelEnvironmentColor" serializeAs="String">
    <value>Orange</value>
</setting>
```

### Default Colors

| Environment | Default Color | Purpose |
|-------------|---------------|---------|
| Development | LightBlue | Local development |
| IT | LightGreen | Integration testing |
| UAT | Yellow | User acceptance testing |
| Parallel | Orange | Parallel/staging environment |
| Production | (system default) | No color change applied |

### Valid Color Values

Any valid .NET color name can be used. Common examples:
- Basic: `Red`, `Green`, `Blue`, `Yellow`, `Orange`, `Purple`, `Pink`, `Cyan`
- Light variants: `LightBlue`, `LightGreen`, `LightYellow`, `LightPink`, `LightCoral`
- Other: `Coral`, `Gold`, `Khaki`, `Lavender`, `Lime`, `Magenta`, `Salmon`, `Turquoise`

Full list available at: https://learn.microsoft.com/en-us/dotnet/api/system.drawing.knowncolor

### Missing or Invalid Configuration

If a color setting is missing or contains an invalid value:
- The application will **not** crash or throw an error
- The TreeView will use the default system background color
- An error will be logged for troubleshooting
