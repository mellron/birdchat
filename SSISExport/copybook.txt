SSISExportDailyCurveMRO CSV Copybook (Full Monthly 1M–360M)

Format
- Delimiter: comma
- Header: yes
- Encoding: UTF-8
- Date format: MM/DD/YYYY
- Quoting: none (no text qualifier)
- Sort: by CURVE, then Date (ascending)

Field Layout
1. CURVE: CHAR(3) — Currency code (e.g., USD, CAD).
2. Date: CHAR(10) — MM/DD/YYYY (e.g., 09/02/2025).
3. O/N: VARCHAR(30) — numeric-as-text; percentage (Value*100).
4. 7D: VARCHAR(30) — numeric-as-text; percentage.
5. 14D: VARCHAR(30) — numeric-as-text; percentage.
6. 21D: VARCHAR(30) — numeric-as-text; percentage.
7. 1M–360M: 360 columns, each VARCHAR(30) — numeric-as-text; percentage. Column names are "1M","2M",...,"360M" corresponding to 1–360 months.
367. Fedtar: VARCHAR(30) — numeric-as-text; percentage; currently blank (reserved).

Notes
- Total columns: 367 (2 identifiers + 4 day-tenors + 360 month-tenors + 1 Fedtar).
- Numeric fields are rendered by SQL as text via CAST((Value*100) AS varchar). They represent percentages; dot is the decimal separator; no thousands separators; may include trailing zeros. Safe consumer type is DECIMAL(18,12) if parsing back to numeric.
- Missing values are output as empty fields.
- CURVE is sourced from LCurrencies.Code (width 3).
- Date is CONVERT(varchar, RateDate, 101) and always 10 characters.
