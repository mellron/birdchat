## Background

US Bank already has a production Message Queue (MQ) infrastructure with established channels to Bank of New York Mellon. This infrastructure is also used by the Swift Messaging Conversion Application Programming Interface (API) to route outbound Bank of New York Mellon messages. The MQ Application Programming Interface (API) handles routing — it receives a message text string and the destination, and puts it on the correct channel.

For Track 1 automation (Fixed Income Clearing Corporation (FICC) trade submission), a new channel to Fixed Income Clearing Corporation (FICC)'s Government Securities Division (GSD) network needs to be established. Kurt confirmed the infrastructure exists but was uncertain whether a Fixed Income Clearing Corporation (FICC)-specific channel has been configured. This story establishes and validates that channel.

**Important**: Fixed Income Clearing Corporation (FICC) / Government Securities Division (GSD) does NOT use the SWIFT network. It uses its own proprietary network for Message Queue (MQ) connectivity. Connection details must come directly from Fixed Income Clearing Corporation (FICC) Integration — contact: ficcintegration@dtcc.com

Reference: `Kurt_info/20260403_KurtConversation.txt`, `Kurt_info/gsd200_gsd_im_member_specs_comparison_io_2023.pdf` (Communications Overview, page 14)

## User Story

**As** the Message Queue (MQ) Application Programming Interface (API),
**I need** a configured, tested, and secured channel to Fixed Income Clearing Corporation (FICC)'s Government Securities Division (GSD) Message Queue network,
**so that** MT515 Trade Input messages can be sent to Fixed Income Clearing Corporation (FICC) and MT509 Trade Status responses can be received.

## Technical Notes

- The GSD200 specification notes (page 7): "GSD utilizes SWIFT standardized messages, but it does not utilize the SWIFT network. GSD currently utilizes its proprietary network for communication between GSD and its Members."
- Fixed Income Clearing Corporation (FICC) connectivity is separate from Bank of New York Mellon connectivity — different host, different credentials, different channel. They happen to use similar message formats.
- FICC Integration contact: **ficcintegration@dtcc.com** — this team handles all member connectivity onboarding
- Sheila (Front Office) may have a prior Fixed Income Clearing Corporation (FICC) technical contact — ask her before reaching out cold to ficcintegration@dtcc.com
- US Bancorp Investments (USBI) Phase 3 already has a Fixed Income Clearing Corporation (FICC) connection — check if their channel configuration can serve as a reference or if the same infrastructure can be shared
