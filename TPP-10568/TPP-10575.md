## Background

Sheila's Delivery Versus Payment / Funding group currently submits trades manually via the Fixed Income Clearing Corporation (FICC) Real-Time Trade Matching (RTTM) website. Management has decided that the replacement workflow will be built inside Collateral Pledging Management System (CPMS) — Sheila will use a new Collateral Pledging Management System (CPMS) screen to review, approve, and monitor Fixed Income Clearing Corporation (FICC) trade submissions.

This screen replaces the manual Real-Time Trade Matching (RTTM) website for Sheila's group. It also provides visibility into Fixed Income Clearing Corporation (FICC) submission status (MT509 responses) so operations staff can confirm trades are accepted and matched without logging into Real-Time Trade Matching (RTTM).

The screen has two functional areas:
1. **Submission queue** — trades loaded from Bank of New York Mellon download (TPP-10574) waiting for review and approval
2. **Status view** — trades already submitted to Fixed Income Clearing Corporation (FICC), showing their current Fixed Income Clearing Corporation (FICC) status (accepted, compared, rejected)

---

## User Story

**As** Sheila (Delivery Versus Payment / Funding Front Office),
**I need** a Collateral Pledging Management System (CPMS) screen where I can review trades loaded from Bank of New York Mellon, approve them for Fixed Income Clearing Corporation (FICC) submission, and see the submission result,
**so that** I no longer need to manually enter trades on the Fixed Income Clearing Corporation (FICC) Real-Time Trade Matching (RTTM) website.

## Screen 1 — Fixed Income Clearing Corporation (FICC) Submission Queue

Displays trades in **"Pending Fixed Income Clearing Corporation (FICC) Submission"** status (loaded by TPP-10574, not yet submitted).

### Minimum Required Columns

| Column | Source |
|---|---|
| Trade Date | Bank of New York Mellon download / Collateral Pledging Management System (CPMS) |
| Settlement Date | Bank of New York Mellon download / Collateral Pledging Management System (CPMS) |
| Transaction Type | Repo / Reverse / Buy / Sell |
| Security (Committee on Uniform Securities Identification Procedures number) | Bank of New York Mellon download |
| Par Amount | Bank of New York Mellon download |
| Repo Rate (for repo trades) | Bank of New York Mellon download |
| Counterparty | Bank of New York Mellon download (internal name) |
| Fixed Income Clearing Corporation (FICC) Contra Firm ID | Resolved via lookup table (TPP-10570) |
| Start Leg Settlement Amount | Bank of New York Mellon download |
| End Leg Settlement Date (for repos) | Bank of New York Mellon download |

### Actions

- **Select** individual trades or select all
- **Submit to Fixed Income Clearing Corporation (FICC)** — triggers MT515 build (TPP-10571) and Message Queue submission (TPP-10573) for selected trades
- **Hold / Do Not Submit** — removes trade from the submission queue without submitting; requires a reason
- **Refresh** — reloads the queue to pick up newly uploaded trades

### Validation Before Submission

- All mandatory MT515 fields must be populated — if any are missing, display a clear per-row error and do not allow submission of that trade
- Counterparty Fixed Income Clearing Corporation (FICC) Firm ID must be resolved — if a counterparty is not found in the lookup table (TPP-10570), display an error and block submission

## Screen 2 — Fixed Income Clearing Corporation (FICC) Submission Status

Displays trades that have been submitted to Fixed Income Clearing Corporation (FICC), with their current MT509 status.

### Minimum Required Columns

| Column | Source |
|---|---|
| Trade Date | Collateral Pledging Management System (CPMS) |
| Settlement Date | Collateral Pledging Management System (CPMS) |
| Transaction Type | Collateral Pledging Management System (CPMS) |
| Security (Committee on Uniform Securities Identification Procedures number) | Collateral Pledging Management System (CPMS) |
| Par Amount | Collateral Pledging Management System (CPMS) |
| Counterparty | Collateral Pledging Management System (CPMS) |
| Submission Timestamp | When MT515 was sent |
| Fixed Income Clearing Corporation (FICC) Status | From MT509 response — Accepted / Rejected / Compared / Canceled |
| Rejection Reason | If status is Rejected — reason code and description from MT509 |
| Last Updated | Timestamp of most recent MT509 received |

### Actions

- **Filter by status** — show only Rejected, only Compared, etc.
- **Filter by date range**
- **Resubmit** — for rejected trades, allows resubmission after correction (if applicable)

## Acceptance Criteria

- [ ] Submission queue screen displays all trades in "Pending Fixed Income Clearing Corporation (FICC) Submission" status with required columns
- [ ] User can select one or multiple trades and click Submit — each selected trade generates an MT515 message and is sent via Message Queue to Fixed Income Clearing Corporation (FICC)
- [ ] Submitted trades move from the queue screen to the status screen immediately upon submission
- [ ] Status screen updates in near-real-time as MT509 responses arrive from Fixed Income Clearing Corporation (FICC)
- [ ] Rejected trades are visually highlighted on the status screen (e.g., red row) and display the rejection reason code in plain language
- [ ] Trades that fail validation (missing fields, unknown counterparty) display a clear error message on the queue screen and cannot be submitted until resolved
- [ ] Hold / Do Not Submit action removes the trade from the queue with a logged reason — trade is not deleted, just marked as held
- [ ] All submission actions are logged with: user, timestamp, action taken, trade reference number (audit trail requirement)
- [ ] Screen is accessible to authorized Collateral Pledging Management System (CPMS) users only — role-based access to be confirmed (see open questions)
