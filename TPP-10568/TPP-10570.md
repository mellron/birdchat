## Background

Every MT515 Trade Input message sent to Fixed Income Clearing Corporation (FICC) requires a **Counterparty (Contra) Firm ID** — this is the counterparty's Fixed Income Clearing Corporation (FICC) member ID, not their name or an internal account number. It is the identifier Fixed Income Clearing Corporation (FICC) uses to route the trade to the correct counterparty member for matching.

On the current manual Real-Time Trade Matching (RTTM) website, Sheila selects this from a dropdown — meaning Fixed Income Clearing Corporation (FICC) already exposes a list of valid member IDs.

For automation, our systems need to know the counterparty's Fixed Income Clearing Corporation (FICC) member ID at the time the message is built. It is very likely that Intrader and Collateral Pledging Management System (CPMS) store counterparties by internal ID or name — not by their Fixed Income Clearing Corporation (FICC) member ID. This story builds the bridge.

Reference: GSD200 Appendix A, field 12 (Buy/Sell) and field 10 (Repo). Full MT515 field specification for the Contra Firm ID field is in `Kurt_info/gsd200_gsd_im_member_specs_comparison_io_2023.pdf`.

## User Story

**As** the Swift Messaging Conversion Application Programming Interface (API),
**I need** a reliable lookup table that maps each known trading counterparty to their Fixed Income Clearing Corporation (FICC) Contra Firm ID,
**so that** when building an MT515 message, the correct Contra Firm ID can be populated automatically without manual intervention.

## Acceptance Criteria

- [ ] Investigate whether Intrader or Collateral Pledging Management System (CPMS) already stores Fixed Income Clearing Corporation (FICC) member IDs for counterparties — document findings
- [ ] If not stored: create a new reference / lookup table (database table or configuration) to hold counterparty Fixed Income Clearing Corporation (FICC) Firm ID mappings
- [ ] Table must contain at minimum:
  - Internal counterparty identifier (as used in Intrader / Collateral Pledging Management System (CPMS))
  - Counterparty name
  - Fixed Income Clearing Corporation (FICC) Contra Firm ID
  - Effective date / active flag (so entries can be deactivated without deletion)
- [ ] Populate the table with all current active trading counterparties
- [ ] The Swift Messaging Conversion Application Programming Interface (API) MT515 message builder (TPP-10571) can call this lookup by internal counterparty ID and receive the correct Fixed Income Clearing Corporation (FICC) Firm ID back
- [ ] If a counterparty is not found in the lookup, the message build must fail with a clear, logged error — do not submit a message with a missing or incorrect Contra Firm ID
- [ ] Provide a mechanism to add / update / deactivate counterparty entries (admin function or script — does not need a user interface)
- [ ] Document the source of Fixed Income Clearing Corporation (FICC) Firm IDs — Fixed Income Clearing Corporation (FICC) publishes a member directory; confirm how to obtain and refresh this list

## Technical Notes

- The Fixed Income Clearing Corporation (FICC) Contra Firm ID is the field that allows Fixed Income Clearing Corporation (FICC) RTTM to notify the counterparty (via MT518 Contra-Side message) that a trade has been submitted against them. An incorrect value means the trade will not match.
- Fixed Income Clearing Corporation (FICC) member IDs can be obtained from the Fixed Income Clearing Corporation (FICC) member directory — contact ficcintegration@dtcc.com to confirm the current process for obtaining and refreshing the member list.
- US Bank's own Fixed Income Clearing Corporation (FICC) member ID is **9286 — US Bank National Association**. This is the Member's Firm ID (field 1), not the Contra Firm ID.
